depression.ai

Understand. Plan. Execute. Verify.

An agentic AI harness that understands your intent, plans the work, executes with real tools, and verifies every change before claiming it's done.

How it works

  1. Understand — reads context and infers what you actually want.
  2. Plan — breaks the task into concrete, verifiable steps.
  3. Execute — runs tools, edits files, runs commands.
  4. Verify — re-reads and re-runs to prove the change works.

Built with

  • Python agent core with a pluggable tool registry
  • Firebase (Google) authentication
  • A terminal UI and this web homepage
