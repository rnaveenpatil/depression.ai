depression.ai — Simple Agent Flow

User prompt → planning → tool loop → final answer

flowchart TD
    A([User types prompt]) --> B[TUI / CLI input]
    B --> C{Plan mode?}
    C -- yes --> D[Planner breaks task into steps]
    C -- no --> E[Skip planning]
    D --> F[[Agent loop]]
    E --> F
    F --> G[LLM picks a tool]
    G --> H{Permission OK?}
    H -- no --> I[Ask user / deny]
    I --> F
    H -- yes --> J[Run tool
filesystem · bash · web · aws]
    J --> K[Result fed back to LLM]
    K --> L{Done?}
    L -- no --> G
    L -- yes --> M([Final answer shown in TUI])
